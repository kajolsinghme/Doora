# Doora

Modern task management board built with React, Redux Toolkit, and responsive UI architecture. Features status-based task workflows, drag-and-drop style organization, global state management with Redux, theme toggling, and clean productivity-focused design.

---

# Overview

Doora is a modern Kanban-style task management application designed for organizing workflows across multiple task states.

The project focuses on frontend architecture, scalable state management, reusable UI components, and responsive design principles.

Built to simulate a real productivity application with clean UX and maintainable frontend structure.
